Reading order under a context budget

  1. head.mechanism + mechanism_tags — cheapest test of whether this mechanism is yours (~200 chars)
  2. head.evidence — at most five verbatim excerpts with locators, one per model family; the only non-paraphrased content, placed first (~100 chars)
  3. gate + needs — whether the thread is actionable, and what it is waiting on (~500 chars)
  4. background — task family, language, model family, harness — the applicability envelope (~600 chars)
  5. rules — if a rule already covers it, equip the rule and stop reading (~900 chars)
  6. tickets[] (full members) and archive — everything the head dropped, and the raw run if you must re-derive (~100 chars)
