EAL001 · v2

Dirty after verification

stableerror

Detect edits made after the final passing verifier.

action sequence

Requires

  • a successful verifier event
  • harness-observed final workspace changes

Abstains when

  • no successful verifier event is available

Remediation: Run the relevant verifier again after the final source change.

EAL002 · v2

Unresolved failure at finish

stableerror

Detect completion after the last compile/test result failed.

action sequence

Requires

  • an observable compile or test result
  • a later run-finished event

Abstains when

  • no verifier outcome is available
  • completion after the failure is not observable

Remediation: Resolve the failure or explicitly stop without claiming completion.

EAL003 · v3

Manifest changed without lockfile

stablewarning

Detect common dependency manifests changed alone.

repository

Requires

  • a known repository lockfile policy
  • a dependency-affecting manifest edit

Abstains when

  • lockfile policy is unknown
  • the manifest diff cannot be classified

Remediation: Regenerate and include the repository's lockfile, or revert the manifest change.

EAL004 · v3

Only a new test was run

experimentalwarning

Detect production changes checked only by a newly added targeted test.

repositoryaction sequence

Requires

  • production and newly added test changes
  • observable test-suite scope

Abstains when

  • no successful test is observable
  • suite scope or targets are unavailable

Remediation: Run the relevant existing suite in addition to the new regression test.

EAL005 · v3

Generated file changed without regeneration

experimentalwarning

Detect generated-looking outputs edited without a generator event.

repositoryaction sequence

Requires

  • confirmed project-generated files
  • complete generator-event capture

Abstains when

  • generated or vendored ownership is unknown
  • generator-event capture is incomplete

Remediation: Change the source and run the generator; record generated paths in the generation event.

EAL006 · v3

Unsupported pre-existing-failure claim

experimentalwarning

Detect pre-existing failure claims without baseline evidence.

harnessaction sequence

Requires

  • a pre-existing-failure claim
  • complete baseline-event capture

Abstains when

  • claim identity fields are missing
  • baseline-event capture is incomplete

Remediation: Run the same verifier against the untouched baseline and record it as baseline_verification.
